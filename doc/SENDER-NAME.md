# 发件人名称

状态：2026-10-17 已部署线上，尚未推送 GitHub。

## 使用

- 写信窗口顶部，在发件邮箱右侧编辑“发件人名称”，点击“保存”。直接发送也会先保存修改后的名称。
- 每个邮箱分别保存，切换发件邮箱会带出该邮箱的名称。不会统一修改其他邮箱。
- 留空保存恢复该邮箱前缀。名称最多 30 个字符，拒绝换行和控制字符，去除尖括号及首尾空格。
- 邮箱菜单也可设置；个人设置对应主邮箱。沿用现有 `account.name`，因此主邮箱的个人名称与发件名称保持一致。
- 保存失败保留输入并停止发送。旧草稿重新读取已保存的名称，历史邮件不变。

## 实现及验证

复用 `PUT /account/setName` 和 `account.name`，不需要数据库迁移；接口检查邮箱归属并返回标准化后的名称。网页发送不再携带缓存名称，后端读取邮箱名称，空名称回退邮箱前缀。站内、Resend 和 Cloudflare 发信共用此处理。

本地验证：后端 35 项、前端 7 项测试通过，生产构建通过。ego-browser 使用假邮箱与模拟保存接口验证分别保存、切换、清空、旧草稿、失败保留及发送前自动保存；覆盖 1440、768、390、320px。没有发送真实邮件，尚未进行线上投递验收。
